## The project

Oosterslicht makes lamps by hand from wood and Japanese paper. The old website was outdated and hard to maintain. I set up a new site that matches the calm of the lamps themselves, and that the family can keep up to date without a website builder.

## What I did

- **Design and build.** A fast, static website in HTML, CSS and JavaScript, with a collection page you can filter by type of lamp and a dedicated page for each lamp with photos, sizes, wood types and paper types.
- **Copy and photography.** I wrote the product copy and shot and edited the product photos myself.
- **Ordering.** A contact and order form, so customers can request a lamp made to measure.
- **Findability.** Every page has its own title, description and structured data for search engines, and the addresses of the old site redirect cleanly to the new ones.
- **Maintenance with my own script.** The same text appears in several places on each page, which quickly drifts apart when edited by hand. So I wrote a Python script that puts all titles and descriptions into one table to edit in Excel, writes them back to the pages, updates the sitemap and checks that everything matches.
